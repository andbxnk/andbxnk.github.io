## 🎨 แนวคิดการออกแบบและฟีเจอร์เด่น (Key Features)

เว็บไซต์ได้รับการพัฒนาภายใต้แนวคิด **Modern Minimalist (สไตล์ Apple + Stripe)** เน้นความสะอาดตา สบายตา ใช้ Font และ Layout ที่เป็นสากล รองรับการทำงานดังนี้:

* **🌓 ระบบ Dark / Light Mode:** สลับโทนสีของเว็บไซต์ (มืด/สว่าง) ได้อย่างนุ่มนวลผ่านปุ่มกดบนแถบ Navbar
* **📱 Fully Responsive Design:** การจัดวาง Layout รองรับการแสดงผลทุกหน้าจออย่างสมบูรณ์แบบ ทั้งบนคอมพิวเตอร์ แท็บเล็ต และสมาร์ตโฟน
* **⌨️ Typing Effect:** เอฟเฟกต์พิมพ์ข้อความแสดงตำแหน่ง/บทบาทบนหน้า Hero Section เพิ่มความน่าสนใจให้เว็บไซต์
* **✨ Animate-on-Scroll:** เอฟเฟกต์ Fade-in เลื่อนปรากฏขึ้นเมื่อผู้ใช้งาน Scroll หน้าจอลงมาถึงเนื้อหาเซกชันนั้นๆ
* **✉️ Contact Form Integration:** แบบฟอร์มติดต่อกลับที่เชื่อมต่อระบบหลังบ้านด้วย **Formspree** สามารถส่งข้อความตรงเข้าสู่อีเมลจริงได้ทันที พร้อมระบบแจ้งเตือน Toast Message (ส่งสำเร็จ/ล้มเหลว)
* **📄 PDF Resume Viewer & Downloader:** มีปุ่มสำหรับกดเปิดดูเรซูเมผ่าน Google Docs Viewer และปุ่มสำหรับดาวน์โหลดไฟล์ PDF ลงเครื่องได้โดยตรง

## 🛠️ เครื่องมือและเทคโนโลยีที่ใช้ (Technologies Used)

* **HTML5** - โครงสร้างเว็บที่เป็นระเบียบ (Semantic HTML)
* **CSS3** - ตกแต่งหน้าตาแบบ Custom Properties (Variables), Flexbox, และ CSS Grid Layout (ไม่มีการใช้ Framework ภายนอก เพื่อให้โค้ดโหลดเร็วที่สุด)
* **Vanilla JavaScript (ES6+)** - ควบคุมระบบสลับธีม, ตัวตรวจจับ Scroll (Intersection Observer API), เอฟเฟกต์การพิมพ์ และระบบส่งฟอร์ม
* **Formspree API** - จัดการระบบรับ-ส่งข้อมูลอีเมลจากฟอร์มติดต่อ
